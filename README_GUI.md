# Zapret GUI

Приложение в трее для запуска обхода вместо `general*.bat`.

## Сборка
`gui\build.bat` (нужен .NET Framework 4.x). Результат: `ZapretGUI.exe` в корне папки zapret. Файл `gui\warp.conf` необязателен: если он есть, его конфиг встраивается в exe (личная сборка), иначе аккаунт WARP создаётся при первом использовании.

## Использование
- Запускать из папки zapret, нужны права администратора.
- Кнопка ВКЛЮЧИТЬ / ВЫКЛЮЧИТЬ запускает и останавливает `bin\winws.exe` с выбранной стратегией. Смена стратегии или игрового фильтра перезапускает обход.
- Закрытие окна сворачивает в трей. Выход: меню трея, пункт «Выход».
- Настройки: `ZapretGUI.ini` рядом с программой.
- Запущенная служба zapret (из `service.bat`) конфликтует с приложением: удалите её на вкладке «Сервис» (она доступна в расширенных настройках).

## Обновления
- В самом верху вкладки «Главная» — кнопка «Проверить обновления» и текущая версия. Проверяется последний релиз https://github.com/boymep/zapret/releases. Если есть новая версия, показываются заметки к релизу и вопрос об установке.
- Установка: скачивается `zapret-<версия>.zip` и `zapret-<версия>.zip.sha256`, проверяется SHA256 (при несовпадении обновление отменяется), архив распаковывается во временную папку, затем обход останавливается, файлы копируются в папку zapret и программа перезапускается. Занятые файлы (в том числе сам `ZapretGUI.exe`) переименовываются в `*.old` и удаляются при следующем запуске.
- Не перезаписываются: `ZapretGUI.ini`, `lists\*-user.txt`, `lists\ipset-all.txt`, `utils\*.enabled`, `utils\test results\`. Файлы `general*.bat`, которых нет в новом релизе, удаляются.
- Если установлена служба zapret, обновление не выполняется: сначала удалите службу на вкладке «Сервис».
- При запуске программа молча проверяет обновления (настройка `check_updates` в `ZapretGUI.ini`, по умолчанию включена; переключатель на вкладке «Настройки»). Если версия новее, показывается уведомление и надпись на главной вкладке; без вашего согласия ничего не устанавливается.

## Автозапуск
Галочка «Запускать вместе с Windows» создаёт задачу планировщика `ZapretGUI` с правами администратора и параметром `--tray`. Снятие галочки удаляет задачу. Чтобы обход включался сам, отметьте «Включать обход при запуске». XML задачи временно записывается в `%ProgramData%\ZapretGUI` (доступ только для SYSTEM и администраторов) под случайным именем и сразу удаляется.

## Вкладки
- **Главная**: сверху кнопка «Проверить обновления» и версия; карточки «Стратегия» и «Игровой фильтр», «Защищённый DNS», «Telegram через прокси» (с кнопкой «Подключить Telegram»), «Веб-версия Telegram через VPN», «YouTube через VPN» с пояснениями; журнал; внизу большая кнопка ВКЛЮЧИТЬ/ВЫКЛЮЧИТЬ и строка состояния.
- **Настройки**: автозапуск с Windows, включение обхода при запуске, сворачивание в трей, проверка обновлений при запуске, сброс WARP-аккаунта.
- **Списки**: редактор пользовательских списков (`list-general-user.txt`, `list-exclude-user.txt`, `ipset-exclude-user.txt`), встроенные списки только для чтения. Пустой файл заменяется строкой-заглушкой.
- **Сервис**: состояние служб, удаление служб zapret и WinDivert, режим и обновление IPSet, проверка hosts, замена активных фейков, диагностика, очистка кэша Discord, тесты.

## Telegram через прокси
Опция «Telegram через прокси» (выключена по умолчанию, ключ `tgEnabled` в `ZapretGUI.ini`) включает встроенный в ZapretGUI MTProto-прокси на `127.0.0.1:1443`. Отдельная программа не нужна, второго значка в трее нет. Прокси работает, пока включён обход и отмечена опция; выключение обхода, снятие опции, выход и установка обновления его останавливают.

- Прокси — перенос основной схемы [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) v1.11.2: соединения Telegram Desktop перешифровываются и идут по WebSocket (`wss://kwsN.web.telegram.org/apiws`) к серверам Telegram. Если WebSocket недоступен, используется прямое TCP-соединение с сервером Telegram. Резервные пути через Cloudflare не перенесены.
- Секрет (32 hex-символа) создаётся один раз и хранится в `ZapretGUI.ini` (`tgSecret`). Прокси, добавленный в Telegram в версии 1.10.3.6, продолжает работать.
- Кнопка «Подключить Telegram» (и пункт меню трея) открывает ссылку `tg://proxy?...` — Telegram Desktop предложит добавить прокси. Это нужно сделать один раз.
- Если порт 1443 занят, прокси не запускается, причина пишется в журнал.
- Остатки версии 1.10.3.6 (процесс и папка `bin\tg-ws-proxy`) удаляются при запуске прокси и при `--cleanup`.
- Проверка: `ZapretGUI.exe --tgproxy-selftest` запускает прокси на свободном порту, отправляет через него запрос `req_pq_multi` в DC2 и печатает OK или FAIL (код выхода 0 или 1).

## VPN через WARP (YouTube, веб-версия Telegram)
Требуется AmneziaWG (`C:Program FilesAmneziaWG`). Две независимые опции (обе выключены по умолчанию): «YouTube через VPN» (`ytEnabled`) и «Веб-версия Telegram через VPN» (`tgWebEnabled`). Пока обход включён и выбрана хотя бы одна опция, поднимается туннель `zapret-tg` (имя осталось с прежних версий), через который идут только подсети выбранных сервисов (объединение списков); остальной трафик идёт напрямую. Переключение опции пересобирает туннель; снятие обеих опций, выключение обхода и выход удаляют его.

- YouTube: встроенный фиксированный список диапазонов Google (youtube.com, googlevideo.com, ytimg), без загрузки из сети. Через WARP идут все фронтенды Google, а не только YouTube; скорость ограничена WARP.
- Веб-версия Telegram (web.telegram.org в браузере): список подсетей берётся с core.telegram.org (запасной встроенный). При этой опции через WARP идёт и трафик встроенного Telegram-прокси к серверам Telegram.
- При обновлении с версии до 1.10.3.6: если раньше была включена опция «Telegram через VPN», веб-версия Telegram через VPN включается автоматически.

Откуда берётся конфиг WARP:
1. Если exe собран с `gui\warp.conf`, используется встроенный конфиг (личная сборка).
2. Иначе используется сохранённый аккаунт `%ProgramData%\ZapretGUI\warp-account.conf`.
3. Если его нет, при первом включении VPN программа регистрирует новый бесплатный аккаунт Cloudflare WARP (на каждом компьютере свой ключ, в программе ключей нет) и сохраняет его с доступом только для SYSTEM и администраторов.

Конфиг туннеля создаётся в `%ProgramData%\ZapretGUI` (AllowedIPs заменяется списком выбранных сервисов, DNS удаляется). Кнопка «Сбросить WARP-аккаунт» (вкладка «Настройки») удаляет сохранённый аккаунт; при следующем включении будет создан новый.

## Защищённый DNS
Зачем: некоторые провайдеры подменяют обычные DNS-ответы (UDP 53) для youtube.com и отдают NXDOMAIN, даже если запрос отправлен на 1.1.1.1 или 8.8.8.8. Ответы по DoH (DNS через HTTPS) приходят верными, а HTTPS к YouTube работает через zapret.

Галочка «Защищённый DNS (DoH через Cloudflare)» (главная вкладка и меню трея) включает шифрованный DNS для всей Windows. Нужна Windows 10 21H2+ или Windows 11; в более старых системах программа покажет сообщение и ничего не изменит.

Что меняется:
- Только физические адаптеры (Ethernet и Wi-Fi, подключённые и со шлюзом). Виртуальные и VPN-адаптеры (Hyper-V, WireGuard, AmneziaWG, TAP, Wintun и т. п.) не затрагиваются, поэтому другие VPN-клиенты не страдают.
- На адаптерах задаются DNS 1.1.1.1 и 1.0.0.1 (и 2606:4700:4700::1111 / ::1001, если включён IPv6).
- Регистрируются шаблоны DoH `https://cloudflare-dns.com/dns-query` (`netsh dns add encryption`), для адаптеров включается режим «только шифрованный» (без запасного UDP), глобально `EnableAutoDoh=2`.

Как восстанавливается: перед первым изменением адаптера прежние настройки (статический или DHCP DNS, ключи DoH, `EnableAutoDoh`, наличие шаблонов) сохраняются в `%ProgramData%\ZapretGUI\dns-backup.ini` (доступ только для SYSTEM и администраторов). Снятие галочки возвращает всё как было, удаляет только добавленные шаблоны и файл резервной копии. При ошибке на адаптере его изменения откатываются.

Настройка сохраняется в `ZapretGUI.ini` (`secureDns`) и не зависит от включения обхода. При запуске программы она тихо применяется повторно (новые сети и адаптеры подхватываются). Текущие DNS показаны на вкладке «Сервис» в разделе «Состояние».

## Очистка
`ZapretGUI.exe --cleanup` без окна завершает winws, удаляет остатки внешнего tg-ws-proxy из версии 1.10.3.6, удаляет туннель zapret-tg, восстанавливает DNS из резервной копии, удаляет задачу автозапуска `ZapretGUI` и драйвер WinDivert (если не запущена служба zapret). Служба zapret не затрагивается. Код выхода 0 при успехе, 1 при ошибках; журнал: `%ProgramData%\ZapretGUI\cleanup.log`.
